_Changes since `v0.12.0`._

This release makes a server safe to open to the internet with sign-up enabled.

✨ New Features

- New accounts must be activated before they can sign in (web, Android app and CalDAV). Activation works through an emailed link or by the server's admin.
- The first account on a server is active at once and becomes the admin. On an existing server, the oldest account becomes the admin.
- Admins activate or remove waiting accounts in **Settings → New accounts**. A badge on the profile picture shows how many are waiting, and admins get an email about new sign-ups (at most one every 15 minutes).
- Optional server mail account (`SMTP_HOST`, `SMTP_PORT`, `SMTP_USE_SSL`, `SMTP_USERNAME`, `SMTP_PASSWORD`, `SMTP_FROM`). It sends activation links (needs `PUBLIC_BASE_URL`) and password-reset emails, so users without a connected mail account can recover their password too.
- New operator commands: `activate-account <email>` (alias `confirm-email`) and `make-admin <email>`.

🔒 Security

- Invitations from other users on the same server are delivered straight into an account only once its email address is proven. Before, anyone could sign up with someone else's address and receive their invitations.
- While sign-up is open, users' mail servers must be on the public internet, so a stranger's account can't reach into your home network. Set `MAIL_HOST_POLICY` to override; once `DISABLE_REGISTRATION=true`, LAN mail servers are allowed again.
- Per-account storage limits for events, tasks, calendars, subscriptions and categories (`QUOTA_*`). Invitations you receive don't count against yours.
- A request limit per account across the API and CalDAV (`API_RATE_LIMIT_PER_MINUTE`, default 1200 a minute, with bursts for a phone's first sync).
- New `FORWARDED_TRUSTED_NETWORKS` setting: only proxies in these networks are trusted to report the visitor's IP address.
- The server sends HSTS over HTTPS, and the bundled nginx now passes on the HTTPS scheme from your reverse proxy.

📦 Deployment & Docs

- Existing accounts stay active after the update; nothing needs to be done for them. The database is migrated automatically.
- If you run an open server, register your own account right after deploying: the first account becomes the admin.
- The Compose file, `.env.example` and Unraid templates no longer pin `MAIL_HOST_POLICY=private`. If you copied that value into your own `.env`, remove it to get the safer default.
- This tag releases the CalendarIT server and web app. Android APKs are published under the separate `24seven-v*` tags.
