_Changes since `v0.5.1`._

🐛 Fixes

- Android: instant updates work. The server encrypted its pushes in an older format that UnifiedPush apps such as ntfy can't pass on readably, so the phone never understood them and changes only arrived with the 15-minute sync. Pushes now use the standard encryption (RFC 8291), and the test push in **Settings → Instant updates** arrives.
- Browser reminders use the same standard encryption.

📦 Deployment & Docs

- Only the server needs updating. No database changes. The APK installs over 24seven 0.5.1.
