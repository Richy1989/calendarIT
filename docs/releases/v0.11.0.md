_Changes since `v0.10.0`._

✨ New Features

- 24seven — CalendarIT has a new name, a new icon and a new default theme, Corner Store. Midnight, Daylight and Graphite are still in Settings → Appearance.
- The 24seven Android app — Offline-first, with several accounts, reminders on the phone, Android's own calendar, a month widget and instant updates through UnifiedPush. This server release is the one the app needs: it adds the app's sync API.
- Tasks — To-dos with due dates, priorities, one level of subtasks and reminders, in a panel next to the calendar. They sync to your phone over CalDAV as VTODO.
- Calendar subscriptions — Subscribe to an .ics or webcal feed (holidays, sports, a colleague's calendar). It refreshes every five minutes and stays read-only.
- "This and following" — Change or delete one occurrence of a repeating appointment and everything after it. Guests get the updates.
- Snooze for browser reminders, a Join button for online meetings, and repeat rules from other apps that you can now edit.
- A collapsible sidebar and one top bar on desktop, which leave more room for the calendar. The month view shows dots for appointments.

🔧 Improvements

- CalDAV incremental sync (RFC 6578): phones fetch only what changed instead of the whole calendar.
- Deleting a whole repeating series now asks first. Undo couldn't bring back its skipped dates and edited occurrences.
- If another tab signs in with a different account, this tab first forgets everything it had cached for the previous one.

🔒 Security

- Password-reset links are never written to the log. If a user has no working mail account, the operator issues a link with `dotnet calendarITCore.dll reset-password-link <email>`, which prints it to their terminal only (see README, "Password recovery").
- Docker Compose no longer falls back to the well-known database password `changeme` — see Deployment.
- Refreshing a sign-in and signing out can no longer race each other: a session you sign out of stays signed out, and a failed refresh no longer signs out every device.

🐛 Fixes

- The app's sync could miss or repeat items when many of them changed at the same moment (for example during an import).

📦 Deployment & Docs

- **Action needed for Docker Compose:** `POSTGRES_PASSWORD` is now required. Existing installations put the password their database was created with into `.env` (`changeme` if they never set one), or rotate it as described in the README, "Database password".
- Your data comes along: the database upgrades itself on first start (new tables for tasks, subscriptions, snoozes and app sync) and keeps everything.
- New demo data for `deploy/seed.ps1` / `seed.sh`.
