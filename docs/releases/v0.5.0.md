_Changes since CalendarIT 0.13.0 (server) and 24seven 0.4.1 (Android)._

From this release on, the server, the web app and the Android app share one version and come out together: every release has the Docker image and the APK.

✨ New Features

- Tasks are part of `.ics` export and import. An export holds each calendar's tasks next to its appointments, and an import brings tasks in with their subtasks.
- **Settings → Users** (was *New accounts*) lists every account on the server, with when it was last active. Admins can activate, disable, delete, make admin or remove admin rights, and create a password-reset link to hand over.
- Disabling an account signs it out everywhere at once (web, app and CalDAV) and keeps its data. A disabled account gets no reminders, mail or feed refreshes until it is enabled again. You can't disable, delete or demote your own account, so a server always keeps an admin.
- Android: CalDAV accounts. No 24seven server needed: choose **CalDAV server** when adding an account and sign in to Nextcloud, Radicale, Baïkal, iCloud (`caldav.icloud.com` with an app-specific password) or any other CalDAV server. Appointments, invitations, tasks with subtasks, phone reminders, the phone's calendar and the month widget all work with them, offline too.
- Android: edits to CalDAV accounts keep what 24seven doesn't show (attachments, other apps' alarms, extra fields). A change made elsewhere first wins, and you're told, with "Apply mine anyway".
- Android: each 24seven account has a **Profile** page (Settings → Accounts → the account's card): your picture, your password, and where you're signed in, with sign-out for any of them.
- Android: **Forgot password?** on the sign-in screen and in the "Sign in again" dialog mails you a reset link.

🔧 Improvements

- Android: task-only lists (as in Nextcloud) are offered only for tasks, and calendars that take no tasks only for appointments.

🐛 Fixes

- A setting left blank (`SMTP_USE_SSL=`, as `.env.example`, Compose and Unraid pass an empty option) now means its default. Before, it could stop the server at start-up.
- Operator commands (`activate-account`, `make-admin`, `reset-password-link`) work again with `docker exec` in the published image.

📦 Deployment & Docs

- The published image is now **`richy1989/24seven`**. On Unraid, change the template's repository from `richy1989/calendarit` to `richy1989/24seven` (your `/data` stays as it is).
- New `docker-compose.image.yml` runs the published image without building. The README shows how.
- The version number restarts at 0.5.0 for everything. If you pinned an image version, move to `richy1989/24seven:0.5.0` or `:latest`.
- The database is migrated automatically. Existing accounts stay as they are.
- Android: if you update from a version before 24seven 0.4.0, add your accounts again. The app's local storage started over in 0.4.0. Sync before you update, because changes that haven't synced yet are lost.
- Android: needs Android 14 or newer. The APK installs over an earlier 24seven APK.
