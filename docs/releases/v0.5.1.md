_Changes since `v0.5.0`._

✨ New Features

- Android: **Settings → Instant updates** walks you through the setup step by step: install a UnifiedPush app (ntfy, linked from the app), turn it on, then send yourself a **test push** that shows whether it arrived and how fast. Once it's on, changes made on the web or another device show up on your phone within seconds.
- Android: instant updates can be turned off again, and stay off.

🔧 Improvements

- Reminders: "Browser" is now called **Notification**, because these reminders ring in the browser *and* in the 24seven app on your phone. Email reminders are sent by the server.
- Choosing a Notification reminder in a browser that blocks notifications now still works (the phone still rings) and only shows a hint.

📦 Deployment & Docs

- No database changes. The APK installs over 24seven 0.5.0.
